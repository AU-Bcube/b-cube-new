# 지침

## 관리자 페이지 컬럼

필수

- 제목
- 연도
- 한 줄 설명
- 형태
- 팀원 (이름 필수, 역할 선택)
- 프로젝트 설명
- 이미지
- PDF

선택 (비어 있으면 화면에서 그 줄을 표시하지 않음)

- 기간
- 수상
- 링크
- 팀원 별 역할

## 화면

- 디자인톤 카드를 누르면 뜨는 모달에서 PDF 위에 정보 테이블을 보여 주고, 아래로 스크롤하면 PDF가 이어진다
- 정보 테이블: 제목 + 한 줄 설명 / 프로젝트 요약(기간 · 형태 · 링크) / 프로젝트 팀원(이름 · 역할) / 프로젝트 설명
- 디자인의 사용 툴, 프로젝트 진행 방식(STEP)은 넣지 않는다

## 데이터

- 시드 스크립트: `pnpm tsx scripts/seed-designton.ts` (입력: `docs/디자인톤_프로젝트_데이터.json`)
- 기존 9건(2023~2024)은 `기존 제목`으로 찾아 정보를 채우고, 2025 · 2026년 9건은 PDF와 썸네일을 R2에 올린 뒤 추가한다
